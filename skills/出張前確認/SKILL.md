出張前の抜け漏れチェックを自動実行してください。

引数: $ARGUMENTS
（例: `/出張前確認` `/出張前確認 2026-05-25` `/出張前確認 大阪` `/出張前確認 クライアントA訪問`）

---

## 実行方針

- **抜け漏れチェックが目的** — 「できているか」を尋ねつつ未対応項目を洗い出す
- **確認なしで一気に走る** — 情報収集・リサーチは自動実行。最後にチェックリストで一括確認
- **事実のみ記載** — 推測・補完なし。情報がない項目は「未確認」「未手配」と明記
- **副作用は出さない** — 新幹線/ホテル/Slack送信などの実際の手配・連絡は本スキルでは行わない（[[confirm-side-effects]]）

---

## STEP 1: 出張イベントの特定

### カレンダーから取得
`mcp__google-calendar__list-events` を使用：
- アカウント: `YOUR_ACCOUNT`
- カレンダーID: `["your-email@example.com", "YOUR_IMPORTED_CALENDAR_ID@import.calendar.google.com", "YOUR_FAMILY_CALENDAR_ID@group.calendar.google.com"]`
- 範囲: 今日から30日先まで（タイムゾーン: Asia/Tokyo）

### 出張候補の抽出
タイトル・場所・descriptionから以下のキーワードを含むイベントを抽出：
- 「出張」「訪問」「現地」「往訪」
- 場所が東京都外（大阪・名古屋・福岡・札幌など）
- 場所が空港・新幹線駅・ホテル名・先方オフィス住所
- `$ARGUMENTS` が日付・地名・案件名なら、それで絞り込み

### 期間の推定
1日のみの場合: 日帰り or 1泊と仮定 → ユーザーに確認
複数日にまたがる連続イベントの場合: その期間を出張期間とする

### 1件に絞れない場合
候補一覧を提示して **1回だけ確認**。1件に絞れたら即 STEP 2 へ。

## STEP 2: 並列リサーチ（4エージェント同時起動）

STEP 1 で出張先・先方が特定できたら、以下を **1つのメッセージで同時に起動**（subagent_type: "general-purpose"）：

**Agent A — 出張期間中の他予定収集：**
```
出張期間 {YYYY-MM-DD}〜{YYYY-MM-DD} のGoogleカレンダー予定をすべて取得し、以下を返してください：
- 出張期間中に重なっている他のMTG・予定（リスケが必要なものリスト）
- 出張前後3日間に入っている重要な予定（事前完了が必要な仕事の判定材料）
- 出張期間中に出席不可となる定例・レビュー
mcp__google-calendar__list-events を使用、カレンダーIDは上記と同じ。
```

**Agent B — 先方リサーチ（会社・担当者）：**
```
出張先の {会社名} と担当者 {担当者名} について以下を調査してください：
1. Web検索MCPで公式HP・直近のニュース・プレスリリース（3ヶ月以内、日付・出典URL付き）
2. 担当者の公開情報（登壇歴・インタビュー・公式プロフィール）— 部長・役員クラスのみ
3. Slack検索で過去の接触履歴・印象・現在の課題・提案状況
公開情報のみ。個人SNSは記載しない。情報なしの項目は「情報なし」と返す。
```

**Agent C — 関連プロジェクト・過去議事録の収集：**
```
${VAULT_PATH}/議事録/ と ${VAULT_PATH}/プロジェクト/ から
「{会社名}」「{案件名}」「{担当者名}」でGrepし、関連する議事録・資料を収集してください：
- 過去議事録の直近3件（日付・タイトル・要点）
- 前回の決定事項・宿題で出張時に持ち込むべきもの
- 案件の現在地（フェーズ・温度感・直近の論点）
```

**Agent D — 出張先の地理情報・移動経路：**
```
Web検索MCPで以下を調査してください：
1. {出張先オフィス住所} の最寄り駅
2. {主要ターミナル駅（新大阪・名古屋・博多など）} から {先方オフィス} までの一般的な移動経路と所要時間
3. {先方オフィス周辺} のホテル候補（ビジネスホテル中心、駅近・徒歩10分以内）
4. {先方オフィス周辺} の会食向き店舗の傾向（ジャンル・予算感）
あくまで参考情報として記載。具体予約は本スキルでは行わない。
```

### 結果の統合
4エージェントの結果が揃ったら STEP 3 へ。

## STEP 4: ユーザーへの質問（最後にまとめて1回）

チェックリストを提示した後、以下を **まとめて1回だけ** 質問：

1. 新幹線・ホテル・稟議申請は手配済みですか？（未済なら期限明示）
2. 出張中の予定共有・リスケは済んでますか？
3. 会食予定はありますか？セッティング状況は？
4. 手土産は購入済みですか？

ユーザーの回答を受けて、未対応項目のみリマインドを出す。

---

## ルール

- **副作用なし** — このスキルは確認用のみ。実際の手配・予約・送信は別途実行する（[[confirm-side-effects]]）
- **タスク登録** — 未対応項目があれば、ユーザーに `/タスク追加` の利用を提案
- **チャットログ記録** — 完了時に [[chatlog]] ルールに従い JSONL を追記
